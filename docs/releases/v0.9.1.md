# FrameGeist v0.9.1 — 侧边栏面板修复 + 墙顶品牌条移除

**补丁版：修复 v0.9.0 中「元素 / 画布 / 导出」三个侧栏 Tab 空白的 HTML 闭合与卡片分组问题；按用户要求移除模板墙顶部品牌展示条。**

## 修复

- **侧栏面板空白（v0.9.0 回归）**
  - 根因一：`web/index.html` 的模板 / 画布两个面板 `<section>` 漏闭合，导致后续 4 个面板被解析为嵌套子面板，三个 Tab 整体不可见；
    补齐闭合标签。
  - 根因二：「添加元素 / 图层 / 元素属性」三张卡被误放进「画布」面板；已移入「元素」面板，五 Tab 分组与契约附录 D 一致。
  - 五个 Tab 现均可正常显示与滚动：模板（模板选择/布局）· 照片（拖放/EXIF）· 元素（添加元素含徽标库/图层/属性/微调/水印）·
    画布（画布/卡片特效/相框/裁切）· 导出。
- **模板墙顶部品牌展示条移除**：删除 `#wallBrandStrip` 及其填充逻辑；灯箱内品牌条与墙卡片品牌标记保留。
- **测试加固**：E2E 新增「每个 Tab 的面板必须真实可见（非嵌套、非隐藏）」断言，可防回归；ungroup 用例改为按稳定 id 选层，
  消除跨次运行的偶发抖动。

## 兼容性

- 引擎、模板、资产、字体零改动；WASM 字节与视觉基线不变；v0.9.0 全部能力与 E2E 断言（271 条）保持全绿。

## 质量门禁（全绿）

- E2E **271/271**；`cargo fmt` / `cargo test --release --workspace` / `clippy -D warnings`；四 target；wasm 构建与字节一致。
- `check-i18n` 485/485、`check-utf8` 0 损坏、`check-brand-colors` 128/128、`check-glyph-coverage` 355 对、UI 对比度全过。
