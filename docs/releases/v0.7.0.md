# FrameGeist v0.7.0 — 品牌徽标系统 + 排版现代化

**192 套模板全面重排；11 组新 OFL 字体（多字重）；官方/原创可切换的相机与镜头徽标；UI 与模板墙/灯箱现代化。**

## 亮点

- **品牌徽标系统 v2**
  - 官方字标（Simple Icons，CC0）与**原创排版 lockup** 两种风格，编辑器一键切换。
  - 42 个品牌 + 12 个镜头系列（GM/G/L/RF L/S/ART/DG DN/APO/XCD/XF/BATIS/SP）；镜头品牌全量补齐
    （Viltrox/老蛙/铭匠/图丽/Samyang/Meike/7Artisans/Sirui/永诺/Voigtländer 等，官方素材缺失时用原创字标）。
  - 可见性规则：尺寸下限（≥3.5% 照片高且 ≥18px）、黑白自适应、花底自动描边/底板、长名最大宽度、
    四角固定、透明度 0.7–1.0；模板水印覆盖 130 → 169 套。
- **排版现代化（DESIGN-LANGUAGE v2）**
  - 新增 11 组 OFL 字体：Fraunces、Bricolage Grotesque、Instrument Serif/Sans、Geist、Geist Mono、Onest、
    Unbounded、得意黑、霞鹜文楷、未来荧黑、更纱黑体；既有字体补齐静态多字重 400/500/600/700。
  - 192 套模板按分类风格体系重排（瑞士 / 编辑 / 日系 / 潮牌 / 器材说明书）；EXIF 数值行默认 Inter tabular（`tnum`）。
  - 字形覆盖门禁（355 组检查，0 缺失），杜绝豆腐块。
- **UI 现代化**：流体字号阶梯（正文 16px）、Geist 可变字体标题、模板墙/灯箱重做、APCA 对比门禁全绿。
- **兼容性**：EXIF 直通、ICC、AVIF/WebP、HEIC、自由拼图等 v0.6 能力保持不变；CLI/WASM 帧渲染字节一致。

## 质量门禁（全绿）

- `cargo fmt` / `cargo test --release --workspace` / `clippy -D warnings`；四 target（wasm32 / aarch64-android / aarch64-ohos / win-x64）。
- WASM：SIMD + wasm-opt -O2，模块 5,058,173 B；WASM↔CLI 帧字节一致，拼图像素差 0.000013。
- E2E **218/218**；视觉回归 384/384（基线因排版换代有意重生成）；性能 4/4（24MP 预览 186ms / 导出 990ms；
  60MP 预览 338ms / 导出 2466ms）；UTF-8 扫描 867 文件 0 损坏。
- 每分类前后对比图：仓库 `docs/reports/v0.7.0/compare/`。

## 资产与许可

- 字体全部 **OFL-1.1**（许可全文 `docs/licenses/fonts/`，来源与 SHA256 见 `SOURCES.md`）；
  品牌字标来自 Simple Icons（CC0）或本项目原创排版，游戏主题仅原创字标。
- **商标声明**：各品牌字标/名称/商标归其权利人所有。本项目仅在照片 EXIF 器材信息展示场景中使用，
  **不表示任何隶属、赞助或背书**；原创 lockup 不复制官方图形徽记。
- 照片零上传；GPS 与序列号导出默认剥离（可显式保留）。
