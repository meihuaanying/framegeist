# FrameGeist v1.4.0 — 12 枚镜头系列徽标第一次真正出现在成品里

发布日期：2026-10-04

## 1. 为每一枚镜头系列徽章配一个模板

自 v0.9.0 起，12 枚镜头系列徽章（索尼 G Master / 索尼 G / 佳能 L / 尼康 S-Line / 适马 ART /
适马 DG DN / 适马 APO / 哈苏 XCD / 富士 XF / 蔡司 Batis / 徕卡 APO / 腾龙 SP）就随徽标库一起
交付，但**没有任何一个模板引用它们**。结果是：v1.2.0 修好的墨迹居中、v1.3.0 做的官方点缀色，
都只在引擎和命令行里成立，产品里看不到。

这一版给每枚徽章配一个角标模板（`series-<slug>-01`），版式沿用已被长期视觉回归验证的游戏
角标几何：深色下带、右下角徽标、右侧一行镜头参数。既有的 192 个模板一个字节都没动，
原有样片零漂移。

现在 Nikon S-Line 模板里，右下角就是**尼康官方黄**的点缀色字标——这是 v1.1.0 记录该色值以来
第一次在产品里出现（实测命中 `#FFE100` 187 px；深色底自动上屏、浅色底按 3:1 对比门禁回退）。

## 2. 新门禁：徽标必须有人用

`tools/check-brand-colors.mjs` 现在断言**每个 series / game 徽标都至少被一个模板引用**
（brand 组豁免，因为模板通过 `{exif.brand_slug}` 动态引用）。这条门禁是为了让
「资产齐了、门禁也过了、但产品里没人渲染」这类故障不可能再悄悄发生——官方点缀色资产就是
这样安静地「已实现但不可达」了一整版的。

门禁总数 275 → **277**。

## 3. 其他

- 模板总数 192 → **204**（`meta.category` 为 `camera`，因为枚举里没有 `series`）；
- 12 张新 showcase 照片按确定性规则分配，并注入真实 EXIF（`check-photo-uniqueness` 要求
  每张照片带真实 EXIF，否则红）；
- 视觉基线 384 → **408**（新增 24 项，既有 384 项未改写）；
- 版本 1.4.0；Rust/JS 全量门禁、E2E、perf、桌面探针全部重跑。
