# FrameGeist v0.9.4 — 画布坐标统一 + 真实鼠标交互修复

> 发布日期：2026-09-24 · 类型：热修（仅修坐标与点选，不含交互模型变更）

## 修复的问题

### 1. 识别框与实物错位（坐标事实来源分裂）

引擎 `layer_boxes` 一直按**全分辨率画布**计算识别框，而编辑器舞台显示的是**预览帧**（长边上限 1600 的快速渲染）。
两者相差约 1.6 倍 → 图层识别框整体偏移、缩放错误。

现在：盒子与画布尺寸**同一次解码**返回（`layer_boxes(..., max_edge)` / `canvas_size(..., max_edge)`），
预览、导出（`max_edge=0` 表示全分辨率）两条路径都拿到与自己显示帧一致的几何，不再混算。

- `crates/framegeist-core/src/boxes.rs`：新增 `canvas_frame()` 与 `layer_boxes_frame_json()`（返回 `{frame, boxes}`），
  `canvas_size_for_photo()` 改用同一公式（修掉忽略 extend 扩展的潜在不一致）。
- `crates/framegeist-wasm/src/lib.rs`：`layer_boxes` / `canvas_size` 增加 `max_edge` 参数。
- `crates/framegeist-cli/src/main.rs`：`boxes` 子命令改用单次解码的新 API，输出格式不变。

### 2. 无法用鼠标直接点选 / 拖动图层

两个原因：

- 每次重渲 `setStage` 都会清空画布容器，编辑器叠加层被销毁重建；
- 渲染后的视图过渡（view transition）快照期间，真实鼠标命中测试落在文档根元素上，点击被吞掉。

现在：舞台图**双缓冲复用**（新帧解码完成才替换，旧帧保持可见），叠加层跨渲染存活；渲染不再使用整页视图过渡。
真实鼠标**首次点击即可命中**，点击空白清除选中，重叠图层点击循环穿透，拖动/缩放/旋转手柄全部可用。

额外稳定性加固（同批落地）：

- 舞台 `pointerdown` 监听从 `#viewport` 上移到 **window（capture）**：浏览器在重负载更新后可能出现合成器命中测试短暂过期（事件被投递给文档根元素），
  改由应用自身按 `#viewport` 几何判定落点，并用 `elementFromPoint` 复核手柄/裁剪框，事件不再丢失。
- 舞台图引用改为每次现取（`stageImg()`），`imgRect()` 允许解码中的 `naturalWidth` 瞬时为 0；
- 新增「显示帧一致性」守卫：舞台短暂显示原图/模板预览（照片注入后的过渡）时，叠加层自动隐藏、点选与「定位到选中」静默不生效，渲染帧上屏后立即恢复——避免过渡窗口内的错位选中；
  守卫同时检查**当前模式**：开过「自由拼贴」再切回模板时不会误判（否则叠加层会被隐藏、点选静默失效）；
- 渲染帧的 blob URL 在新帧上屏后立即释放（灯箱同规则），修复长时间会话的显存/内存泄漏。

### 3. 选中后画布被自动平移挤出屏幕

删除全部「选中自动平移」逻辑；选中与拖动**不再改变视图缩放和平移**。
新增 **定位到选中** 按钮（工具栏 ◎，`stage.locate`，四语言）：仅在用户主动缩放/平移后需要时，手动把选中对象拉回视口
（居中后只对选中盒做视口内收敛，不再把对象推出屏幕）。

### 4. 形状层识别框与渲染器不一致

`Layer::Shape` 的盒子此前使用硬编码尺寸，与渲染器规则不同（分割条 / 圆点 / 边框角色错位）。
现在完全镜像 `render.rs::draw_shape_layer`：尺寸按照片比例、`span:"auto"` 的 inset 规则、`frame` 角色的边距矩形。

### 5. 选中框与手柄的屏幕尺寸

选中框线宽改为 `1.5px × 1/zoom`（屏幕恒定），手柄保持 24×24 屏幕像素命中区，缩放到 400% 也不变形。

- 新增真实输入探针 `target/probe-realclick.mjs`：13/13（盒对齐、逐层点击、拖拽、导出路径帧一致）。
- Rust：`cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --release --workspace`（含 golden 回归）全部通过。
- 多目标：win / wasm32-unknown-unknown / aarch64-linux-android / aarch64-unknown-linux-ohos。
- WASM 重建 + 帧字节一致（5,061,848 B）；JS 检查：i18n 487/487、brand-colors 169/169、ui-contrast、glyph 192 模板/355 对、utf8 928 文件、photo-uniqueness、templates 192/192。

## 兼容性

- 模板 JSON、品牌资产、导出格式**无变更**；渲染像素未改动（本次只改识别框与交互层），样片与视觉基线无需重生成。
- 编辑器行为变化：选中不再自动平移（改用「定位到选中」按钮）；首次点击即选中，无需二次点击。
