# FrameGeist v0.8.0 — 徽标库 + 全中文界面 + 默认尺寸提升

**右侧「徽标库」四组可选可搜可收藏，按图层一键替换并恢复 EXIF 自动识别；应用控件全量中文化；模板字号与徽标默认尺寸显著放大且越界为零。**

## 亮点

- **徽标库（Badge library）**
  - 右侧栏独立卡片：四组徽标 —— 相机品牌 28 / 镜头品牌 38 / 系列徽章 13 / 游戏字标 6，共 85 项；
    96px 预生成缩略图（暗色自动反色）、搜索跨组、**收藏 / 最近使用**（localStorage）。
  - **图层级替换**：点击即替换当前选中图层；未选中时自动选中模板第一个徽标层并提示；
    顶部「自动识别（EXIF）」把该层恢复为表达式；官方字标 / 原创排版风格开关联动改写实体层。
  - 模板墙：顶栏「徽标库」浏览弹层 + 卡片品牌标记（表达式层用中性「EXIF」原创标；175/192 套有标记）。
- **中文界面**
  - 应用控件全量中文化（按钮/面板/图层类型/toast/错误/aria/alt/title），zh/en 键 100% 对齐（380/380），
    新增 `tools/check-i18n.mjs` 门禁 + E2E 可见文本英文残留扫描；模板艺术文字与 EXIF 单位保持原样。
  - 并入 v0.7.0 发布后修复：字体请求超时、按文件字重追踪、灯箱品牌条类名冲突。
- **默认尺寸提升**
  - 引擎：徽标下限 3.5%→**5%**（仍 ≥18px）、默认层高 3%→**4.5%**、最大宽 32%→**38%**。
  - 模板：Data/Label ×1.2、Support ×1.1（Display 不变，下限 0.0095）；192 套重排、178 个徽标层抬高，
    越界/重叠自动回退 6 套 12 层、0 未解决（`docs/reports/v0.8.0/typography-report.json`）。
  - 字体补齐 **Instrument Serif**（OFL 静态 400）→ 69 faces / 23 families。
- **性能与首启**：墙卡/库格子 `content-visibility` 与懒加载；启动墙骨架与首启分级提示。
- **兼容性**：v0.7 全部能力（EXIF/ICC/AVIF/WebP/HEIC/自由拼图/模板墙/灯箱/批量）不回归；WASM↔CLI 帧字节一致。

## 质量门禁（全绿）

- `cargo fmt` / `cargo test --release --workspace` / `clippy -D warnings`；四 target（wasm32 / aarch64-android / aarch64-ohos / win-x64）。
- WASM：SIMD + wasm-opt -O2，模块 **5,058,426 B**；WASM↔CLI 帧字节一致，拼图像素差 0.000013。
- E2E **235/235**；视觉回归 384/384（基线因字号/徽标默认变化有意重生成）；性能 4/4

- 模板 192/192 校验、字形覆盖 355 对 0 缺失、i18n 380/380、UI 对比度 APCA 全过。
- 每分类前后对比图：`docs/reports/v0.8.0/compare/`（v0.7.0 左 / v0.8.0 右，25 分类 × 3 套）。
