# FrameGeist v0.9.2 — 预览居中修复 + Canon 官方红徽标

**补丁版：修复编辑器模板预览默认打开时偏移/被裁的问题；按用户反馈把 Canon 徽标恢复为官方红（原创字标着色）。**

## 修复

- **编辑器预览居中**：`.canvas-wrap` 的 grid 居中与 `fitStage()` 的平移叠加，导致无照片时的模板预览图向右下偏移、底部被裁；
  移除多余居中后，模板预览与照片预览均精确居中且完整可见（E2E 新增回归断言）。
- **Canon 徽标官方红**：Simple Icons 下架 Canon 后项目使用原创排版字标，但主变体为黑色；现按公开的 Canon 官方红
  （Pantone 186 C ≈ `#C8102E`）为原创字标着色（`brand/canon` 与 `lockup/canon` 主变体），`-mono`/`-light` 黑白回退保留。
  **字标为原创排版，不复制官方图形徽记**；色值锁定在 `tools/brand-colors.json` 的 `originalColorOverride`。

## 兼容性

- 引擎、模板 JSON、WASM 零改动；v0.9.0/v0.9.1 全部能力与 E2E 断言保持全绿（现 **273/273**）。
- 视觉基线因 Canon 主变体黑→红**有意重生成**（384 项），复核全绿；样片 192/192 重渲。

## 质量门禁（全绿）

- `cargo fmt` / `cargo test --release --workspace` / `clippy -D warnings`；四 target；wasm 字节一致。
- `check-i18n` 485/485、`check-utf8` 0 损坏、`check-brand-colors` **131/131**、`check-glyph-coverage` 355 对、UI 对比度全过。
