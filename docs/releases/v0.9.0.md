# FrameGeist v0.9.0 — 彩色徽标 + 画布直操 + 五 Tab 侧边栏 + 徽标库集成

**官方品牌色回归徽标（对比不足自动回退黑白）；模板徽标默认放大到 6.5%；侧边栏五 Tab 零遮挡；画布可直接点选/拖移/缩放/旋转/删除；徽标库并入「添加元素」且筛选真正生效。**

## 亮点

- **彩色品牌徽标（Colorful badges）**
  - 采集 Simple Icons 官方 hex，按阈值规则（HSL `s ≥ 0.18` 且 `0.10 ≤ l ≤ 0.90`）判定 **15 个彩色品牌**（nikon/fujifilm/leica/panasonic/epson/insta360/samsung/vivo/oppo/oneplus/huawei/google/motorola/nokia/blackmagicdesign）；
    sony/dji/apple/honor 官方色即黑/白，保持单色；Simple Icons 已下架的品牌（canon 等）继续使用原创排版 mono，不臆造官方色。
  - 主变体默认上官方色；局部背景对比不足 3:1（WCAG 1.4.11）时自动回退黑/白变体（`-mono`/`-light`），仍不足再加描边/底板；
    属性面板新增「官方彩色」（`tint/contrast:"color"`）可强制彩色。新增 `-mono` 变体，锁定清单 `tools/brand-colors.json`，像素门禁 `check-brand-colors` **128/128**。
  - 同一品牌的官方字标与原创 lockup 同色；暗色主题缩略图与模板墙卡片标记同步彩色；series/game 保持单色。
- **徽标尺寸再提升**
  - 引擎默认层高 4.5%→**6.5%**、下限 5%→**6%**（仍 ≥18px）、最大宽 38%→**44%**；192 套模板徽标层批量 ×1.3（上界 0.12），
    越界/重叠守卫回退 1 套（记录在 `docs/reports/v0.9.0/typography-report.json`），其余 190 个徽标层全部 ≥6%。
- **五 Tab 侧边栏 + 紧凑导出条**
  - 模板 / 照片 / 元素 / 画布 / 导出五个分区，单一滚动区；底部导出条（≤56px）常驻「渲染预览 / 导出 / 尺寸·格式摘要」，不再遮挡内容；Tab 选择本地记忆；移除简单/高级 tier。
  - 属性标签与图层名全量中文化（zh/en **485 键**对齐；`check-i18n` 新增「属性标签必须是 i18n key」规则）。
- **画布直接操作（Direct manipulation）**
  - 点选（重叠再点循环穿透）+ Shift 多选 + 拖移吸附参考线 + 四角等比缩放（文本改字号，图片/徽标/形状/日历/色卡改尺寸）+
    文本与形状旋转（15° 吸附）+ Delete/Backspace 删除 + 选区浮动工具条（删除/复制/置顶/置底/锁定）。
  - 手柄视觉 10px 圆点 + **≥24px 隐形命中区**（粗指针 14/32px，WCAG 2.5.8）；空格/中键平移、缩放下拉（fit/50–200%）、
    选中自动移入视野、状态栏画布尺寸 `W × H px`。
- **徽标库并入「添加元素」**
  - 点「徽标」展开内嵌库：分组 chips 单选过滤（全部 / 相机 28 / 镜头 38 / 系列 13 / 游戏 6）+ 组内搜索 + 收藏/最近快捷行 +
    EXIF 自动识别恢复 + 自定义上传；无徽标层时一键新增并选中。
  - 选中徽标层可开启「本图层单独覆盖」（位置/大小/对比/不透明度写图层字段，取消勾选回落模板级）；
    优先级 **图层字段 > 模板级 override > 模板 JSON**。移除墙顶入口与只读弹层。
- **兼容性**：v0.7/v0.8 全部能力（EXIF/ICC/AVIF/WebP/HEIC/自由拼图/模板墙/灯箱/批量）不回归；`fg-tpl-edits-v1` 旧数据可读；
  WASM↔CLI 帧字节一致。

## 质量门禁（全绿）

- `cargo fmt` / `cargo test --release --workspace` / `clippy -D warnings`；四 target（win-x64 / wasm32 / aarch64-android / aarch64-ohos）。
- WASM：SIMD + wasm-opt -O2，模块 **5,059,244 B**；WASM↔CLI 帧字节一致，拼图像素差 0.000013。
- E2E **271/271**（v0.8 的 235 全保留 + v0.9 新增 36 条）；视觉回归 **384/384**（基线因彩色/尺寸/阈值变化**有意重生成**）；
  性能 **4/4**（24MP 预览 171ms / 导出 914ms；60MP 预览 295ms / 导出 2256ms）；UTF-8 扫描 913 文件 0 损坏。
- 模板 192/192 校验、字形覆盖 355 对 0 缺失、i18n 485/485、UI 对比度 APCA 全过、品牌色像素校验 128/128。
- 每分类前后对比图：`docs/reports/v0.9.0/compare/`（v0.8.0 左 / v0.9.0 右，25 分类 × 3 套）。

## 资产与许可

- 品牌字标来自 Simple Icons（CC0-1.0）或本项目原创排版；彩色化仅使用该库的 **hex 元数据 + 单色路径重绘**，
  不引入多色官方插画；游戏主题仅原创字标。
- 字体全部 **OFL-1.1**（许可全文 `docs/licenses/fonts/`，来源与 SHA256 见 `SOURCES.md`）。
- **商标声明**：各品牌字标/名称/商标归其权利人所有。本项目仅在照片 EXIF 器材信息展示场景中使用，
  **不表示任何隶属、赞助或背书**；原创 lockup 不复制官方图形徽记。
- 照片零上传；GPS 与序列号导出默认剥离（可显式保留）。
