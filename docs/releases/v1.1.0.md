# FrameGeist v1.1.0 —— 官方品牌素材落地（22 项官方标识）

v1.0.0 完成了排版引擎与体验三项。本版本把 `docs/reports/v1.0.0/brand-audit.md` 的审计结论落地：**22 个品牌徽标换用官方标识**，并首次落地「系列徽章官方点缀色」的机制。

## 1. 官方素材落地（22 项）

由你交付的 `brand-official-inbox/`（不入库）经 `tools/import-brand-inbox.mjs` 导入，产物写入 `templates/assets/brand/` + `web/brand/`（含 `-mono` / `-light` / `thumbs`）：

- **官方原色标识**：Google 官方四色、Leica 官方红圆徽标、ZEISS 官方蓝盾、HUAWEI 官方红花、Nokia 官方蓝、insta360 官方黄、7artisans 官方红、Phase One 官方蓝、SIRUI、Meike、Nikon 官方黄底方块、Samsung、Oppo、vivo 等。
- **官方字形 + 官方色重着色**（单色规范）：Apple 保留 Simple Icons 字标、Blackmagic Design、Epson、HONOR、Sony、Viltrox 等。
- **Voigtländer 改用 cosina.jp 官方书法体** —— 审计报告中差异最大的一项（全大写衬线 → 官方手写体）。
- **Nikon 特殊处理**：官方素材是不透明黄底方块，作主变体；既有黑白字标变体保留（浅色背景仍可回退）。

## 2. manifest v5 与系列点缀色机制

- `web/brand/index.json` 升至 **v5**，新增 `officialAsset` / `sourceUrl` / `color`（资产实测色）/ `lightOfficial` / `tintSkipped`，系列徽章支持 `accent` 官方点缀色。
- **`nikon-s` 记录官方点缀色 `#FFE100`**（S-Line 官方黄）。其余 12 个系列徽章经核对**官方从未作为独立徽标图发布**（仅以镜身刻字照片/网页排印出现），暂保留单色版并记录原因 —— 待官方素材到位即可填入，机制已就位。
  - ⚠️ 需要说清的一点：本次交付的 S-Line 官方标识本身是**单色黑字标**，因此**今天渲染出来的仍是官方单色标识**（引擎按背景对比度自动选黑/白变体，与其余 12 枚系列徽章一致）。`accent: #FFE100` 记录的是裁决 5 要求的**尼康官方品牌黄**，作为后续「官方配色变体」的占位；引擎目前只对**带色的主资产**渲染彩色（`use_color = primary_colorful && …`），所以该字段现阶段是元数据，尚未被任何代码消费。补齐它需要引擎支持 `-color` 变体，已列入 v1.2 backlog。
- **移除 `canon-rf-l`**：按裁决 6「只保留 L」，`canon-l` 已是单独的 L 字标 + 官方红。

## 3. 品牌色门禁升级（`check-brand-colors`）

判色口径从「全墨迹平均饱和度」改为**主导色相覆盖率**（`hueShare >= 0.5`）：官方字标常是「黑字标 + 少量彩色」（如 Blackmagic 的橙方块、7artisans 的红 7），平均饱和度无法区分二者，会产生大量假阳性。新增 `tintSkipped` / `lightOfficial` 感知（不透明方形标保留旧变体、官方浅色 plate 允许非白）。

门禁项数由 142 增至 **250**，其中 **8 项为新增的几何检查**：ink 宽高比 > 2.2 的字标必须满足 `ink.h <= 0.34 × canvas.h`。原因是引擎按**高度**确定徽标尺寸、再乘画布纵横比得到宽度，画布占位一旦偏离既有约定，字标就会被放大到压住信息块文字 —— 而像素与色值门禁完全看不出这类问题（见下节）。

## 4. 两轮渲染回归与修复

导入后的对比图目视复核发现两处真实回归，**单测与像素/色值门禁均未报警**：

1. **宽画布放大字标、压住信息块文字**：`phone-accent-dots-01` / `phone-paper-spec-01` / `phone-vendor-bar-01` 三套的 SONY 字标压在 `1/250s · ISO100` 等文字上。根因是首版导入器产出 2048×512 的宽画布，引擎按纵横比把字标放大约 4 倍。修复：画布改为**正方形 512×512**、墨迹居中 —— 新旧 SONY 资产画布与墨迹逐像素一致。
2. **宽字标墨迹高度偏高 1.44 倍**：正方形画布下按宽度定尺寸，7artisans 的墨迹高占画布 0.447（v1.0.0 基线为 0.309），在画面上明显偏大。修复：`ink.w / ink.h > 2.2` 的字标改按**墨迹高度**定尺寸（`WORDMARK_INK_H_RATIO = 0.3125` = 160/512，与既有资产一致）；方形标识（Leica / Nikon / ZEISS）仍填满方框。

因此新增第 3 节的 8 项几何门禁，并确立写入纪律：**更换徽标资产必须先对比新旧几何、再跑像素与色值门禁、最后目视对比图** —— 门禁全绿不等于布局安全。
