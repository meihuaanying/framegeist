# FrameGeist v0.9.3 — Canon 官方字形 + 手机品牌独立分组

**补丁版：Canon 徽标改用更接近官方字形的厚重衬线排版；徽章库新增「手机品牌」分组。**

## 修复

- **Canon 字标**：按用户提供的官方图对照，将原创排版字标从 Cormorant Garamond（高对比纤细）换成
  **Noto Serif SC 700**（厚重过渡衬线、中等对比、字距收紧），官方红 `#C8102E` 不变；
  `brand/canon` 与 `lockup/canon` 三变体已重渲。**字形为原创排版，不复制官方矢量徽记。**
- **徽章库分组**：清单升级 **v4**，新增 **手机品牌（10）** 独立分组 ——
  相机品牌 18 · **手机品牌 10** · 镜头品牌 28 · 系列徽章 13 · 游戏字标 6（全部 75）；
  分组 chip、组内搜索、收藏/最近、插入/替换流程全部适配。
- **取消分组位置漂移修复**：原实现用舞台图片尺寸换算图层偏移，渲染中/失败时舞台显示原图会导致 group→ungroup 位置漂移
  （实测最高 2332px）；现由引擎提供画布尺寸（wasm 新增 `canvas_size` API）后再换算，对齐/分布同步修复。

## 兼容性

- 引擎、模板 JSON、WASM 零改动；v0.9.0–v0.9.2 全部能力与 E2E 断言保持全绿（现 **274/274**）。
- 视觉基线因 Canon 字形更换**有意重生成**（384 项），复核全绿；样片 192/192 重渲。
- 旧版 `brand/index.json`（v2/v3）读取兼容保留（数组与缺组回退）。

## 质量门禁（全绿）

- `cargo fmt` / `cargo test --release --workspace` / `clippy -D warnings`；四 target；wasm 字节一致。
- `check-i18n` 486/486、`check-utf8` 0 损坏、`check-brand-colors` **169/169**、`check-glyph-coverage` 355 对、UI 对比度全过。
