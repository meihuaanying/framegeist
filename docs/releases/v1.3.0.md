# FrameGeist v1.3.0 — 信息块行编辑器 + 官方点缀色真正上屏 + 宿主徽标面补齐

发布日期：2026-10-02

## 1. 信息块行编辑器：把 v1.0.0 迁移后「看得见、点不动」的信息块变成可编辑

v1.0.0 把品牌信息从文本层迁成了引擎级 `infoBlock`（自动排版：字阶 display 1.00 /
support 0.72 / detail 0.58，按留白填满 2/3），但行编辑器仍只遍历文本层 —— 信息块在
画布上正常工作，用户却改不了它的行。现在信息块作为行编辑器里的一个分组出现：

- 每行一个**层级选择**（主标题 / 副标题 / 细节），直接对应引擎的逐行字阶；
- 增 / 删 / ↑↓ 重排全部可用，行数上下限（1–3）由 UI 直接对齐引擎校验，
  触顶时「添加」按钮禁用、触底时删除按钮禁用 —— **界面上造不出引擎会拒绝的状态**；
- 复用既有的字段 chip（`{model}` / `{focal}` / `{iso}` …）插入到当前聚焦的行；
- 「重置」一键还原模板自带的行；
- 编辑随模板归档（localStorage `fg-line-edits`），换模板回来仍在。

细节：改文字会保留该行原有的语义层级（避免改个错别字就把主标题降级成副标题）。

## 2. `import-brand-inbox --accent`：兑现 v1.2.0 的承诺，第一个官方点缀色资产已上屏

v1.2.0 的说明里写着「素材到位后跑 `import-brand-inbox --accent` 一次上色」，但那个参数
当时并不存在 —— `nikon-s.accent` 一直只是 manifest 元数据。现在参数与链路都已就位：

```bash
# 官方素材只给色值时，生成同几何的 -accent 面
node tools/import-brand-inbox.mjs --accent series-slug=#FFE100
```

- 只有**单色素材**才生成 accent 面（不透明墨迹均值色的距离 ≤32 占比 ≥95%），
  避免给双色/插画素材套色变成二选一的假资产；整幅不透明徽章直接跳过；
- 生成的 `-accent.png` 与 base 面**几何逐像素一致**（同一个 ink 盒、同一主高度），只换颜色；
- 产物：`templates/assets/series/nikon-s-accent.png`（Nikon 官方黄 `#FFE100`），
  manifest 新增 `accentAsset` 标记。

实测（合成模板 + CLI 渲染后扫描输出像素）：

| 场景 | 结果 |
|---|---|
| 深色底 + 模板显式要求彩色 | 命中 `#FFE100` **604 px**（容差内 1111 px）→ 上屏 |
| 深色底，模板**不给任何提示** | 结果完全相同 → 3:1 对比门禁自动放行，作者无需写 `tint`/`contrast` |
| 浅色底 | 命中 **0 px** → 自动回退黑白 |

## 3. ★ 修复：Web 宿主只注册了两个徽标面

内建资产注册点（`ensureBuiltinAssets`）此前只请求 `""` 与 `-light` 两个面，
于是 v1.2.0 的 `-accent` 面与 v0.9 就存在的 `-mono` 面**在浏览器里根本拿不到**：
引擎的 Accent 分支只在命令行可用，网页上是死代码；「彩色对比不足自动回退黑白」的
口径也没真正生效。现在改为遍历全部面（`-light` / `-mono` / `-accent`），
缺失的面静默跳过。命令行路径不受影响（本就回落磁盘）。

## 4. 门禁

`tools/check-brand-colors.mjs` 由 268 扩到 **275 项**（三条 accent 契约 + 四条镜像一致性）：
- `accentAsset` 声明与 `-accent` 文件存在性双向一致；
- accent 面与 base 面几何完全一致（ink + 水平/垂直留白三项相等）；
- accent 面像素色等于声明色（色相距离 ≤45°、平均饱和度 ≥0.2）；
- `web/<kind>/` 与 `templates/assets/<kind>/` 双向文件名一致 —— 浏览器实际从 `web/` 取面，
  此前是纯手工镜像：accent 面磁盘上有、网页 404，canon-rf-l 从 manifest 移除后却残留在 `web/`。
  门禁现在两侧都查，已补 `web/series/nikon-s-mono.png`、清掉两个 canon-rf-l 幽灵文件。

## 5. 兼容性

- 模板 schema、`meta.version`、`minEngineVersion` 全部未变；旧模板渲染**逐字节不变**

- 未提供 `-accent` / `-mono` 面的徽标行为不变；
- 设置键与 manifest 字段只增不改（仍为 manifest v5）。
