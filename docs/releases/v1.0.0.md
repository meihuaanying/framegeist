# FrameGeist v1.0.0 — 留白排版信息块 · 徽标官方化审计 · 调研改进落地

v1.0.0 是排版引擎的一次结构性升级：新增 **信息块（infoBlock）**，文字只在留白区内自动拟合（填满留白 2/3、最多 3 行、集中在单一侧、永不覆盖照片），并把 192 套模板全量迁移到新排版；同时完成 57 项徽标的官方样式审计与 12 条裁决落地，以及竞品调研选定的 3 项体验改进（快捷键速查表、导出预设、批量导出命名）。

## 1. 引擎：留白区自动排版（infoBlock）

- 新字段 `infoBlock`（见 `docs/TEMPLATE-SPEC.md §4.7` 与 `docs/schema/template.schema.json`）：
  - `side: left | right | bottom`（同一套模板的文字集中在单一侧，成组呈现）
  - `font.family`（1–8 个候选，含 CJK 回退）、可选 `font.weight` 覆盖
  - `lines`（1–3 行；逐行 `expr` / `fallback` / `role`，角色字阶 `display` 1.00 / `support` 0.72 / `detail` 0.58）
  - `align` / `fill`（默认 2/3）/ `sizeMin` / `sizeMax` / `lineHeight` / `color` / `z`
- 求解器 `text_fit` 是渲染器与几何 API（`boxes`）的**唯一事实来源**，保证叠加层与像素一致（±2px）
- 硬保证（Rust `engine_v100.rs` 全绿）：填满留白区 2/3（下侧按高度、左/右按宽度）；最多 3 行；不越出留白区；**永不覆盖照片像素**；输出确定性；无 `infoBlock` 的旧模板渲染字节不变
- 设计语言草案与样张：`docs/reports/v1.0.0/DESIGN-LANGUAGE-v3-DRAFT.md`、`docs/reports/v1.0.0/samples/`（6 套 + 7 张渲染）

## 2. 模板：192 套全量重排

- 迁移工具 `tools/apply-v100-typography.mjs`：焦点层定侧、≤3 行按角色排序、多字段以 ` · ` 连接、剥除悬空 `attachTo`、必要时改 `extend` 并补留白与背景；每套模板经 CLI `boxes` 几何守卫（失败回滚）；支持 `--dry` / `--apply` / `--only` / `--force`
- 结果：**migrated 192 / skipped 0 / failed 0**（下侧 189、左侧 1、右侧 2）；`meta.version 1.4.0`、`minEngineVersion 1.0.0`
- 逐套记录：`docs/reports/v1.0.0/typography-v100-report.json`

## 3. 徽标：57 项官方样式审计 + 12 条裁决

- 交付物：`docs/reports/v1.0.0/brand-audit.md`（相机 18 / 手机 10 / 系列 13 / 游戏 6）、`brand-audit-lens.md`（镜头 10）、`brand-delivery-checklist.md`
- 已落地的裁决：
  - 颜色维持 Simple Icons 口径（nikon、insta360、fujifilm、huawei、motorola、blackmagicdesign 的官方色不变）
  - 官方字标/标识经授权使用，素材由权利方提供（投放目录 `brand-official-inbox/`，不入库）
  - 手机品牌显示名中文本地化（苹果 / 谷歌 / 荣耀 / 华为 / 摩托罗拉 / 诺基亚 / 一加 / OPPO / 三星 / vivo）
  - 保留 OLYMPUS / Panasonic 画面文字（旧机型兼容）
  - Canon 系列徽标只保留「L」（配官方红点缀）
  - 浅底自动改用黑色 `-mono` 变体（黄字白底对比度保护）
  - 游戏 IP 声明写入 `docs/CREDITS.md`
- 字形覆盖门禁：192 套 / 279 family-char 对 / 0 缺字

## 4. 体验改进（竞品调研选定 3 项）

- **快捷键 + 速查表（`?`）**：`E` 导出、`Ctrl+Shift+E` 批量导出、`F` 适应窗口、`0` 100%、`+` / `-` 缩放、`L` 定位到选中；输入框聚焦时一律不触发
- **导出预设**：微信分享 · 2K / 社媒 · 4K / 归档 · 原图 / 网页 · 4K，可另存为自定义预设；导出面板 chip 一键切换，导出栏同步显示预设名
- **批量导出命名**：`{name}` `{tpl}` `{tplName}` `{date}` `{seq}` `{size}` `{fmt}` 模板、实时预览、冲突策略（追加序号 / 覆盖 / 跳过）
- 调研与提案：`docs/reports/v1.0.0/RESEARCH.md`、`IMPROVEMENTS.md`（P4–P8 列入 v1.1）
