## 0. 方法与时效声明

- **写作口径**：中文，表格优先；「可借鉴点」必须能落到 FrameGeist 现有能力或明确的新提案，不做无边界畅想。
- **事实纪律**：2026-09-24 本机网络仅 `bing.com` / `baidu.com` 可达，多数厂商官网 403 或超时。本次只做了 2 次 bing 检索（Photoroom、今日水印相机），**未取得可信的价格/版本信息**；因此文中所有价格、订阅档位、模板数量、最新版本号一律标注「约 / 不确定（截至 2024 年知识）」，不作为决策依据。功能描述以公开产品印象为准，若与最新版本不符以官方为准。
- **FrameGeist 基线（v0.9.4 事实，用于对照）**：离线优先的边框 / 水印排版工具；Web PWA（Rust→wasm 引擎，确定性渲染）+ Tauri 桌面端 + CLI；192 套模板 / 25 个分类；品牌徽章库 75 项分 5 组（相机 18 / 手机 10 / 镜头 28 / 系列 13 / 游戏 6），v1.0.0 逐项核对其中 47 项；导出 JPEG/PNG/AVIF/WebP + 尺寸档位（原图 / 2K / 4K / 6K / 720P / 自定义长边）；拼贴 + 自由拼贴；裁剪 / 旋转 / 翻转 / 背景 / 边距 / 边框；4 locale（zh-CN / zh-TW / en ×2）；键盘快捷键（方向键微调 1px、Shift 10px、Ctrl+Z/Y、Esc、Ctrl+滚轮缩放、空格平移、Ctrl+, 设置）；无账号、无云；MIT 开源。v0.9.4 刚修复：画布坐标统一、真实鼠标点选 / 拖拽、取消选中自动平移 + 「定位到选中」按钮。
- **维度定义**（每家 7 行功能矩阵固定用）：模板体系、排版与水印、品牌徽标或 Logo、导出（格式 / 尺寸 / 批量）、编辑交互（点选 / 图层 / 手势）、离线与云、收费模式。

## 1. 国内 4 家

### 1.1 边框精灵（FrameElf）

- **定位与目标用户**：国内起家的「照片加边框 / 水印」工具，主打把 EXIF 参数与机型 / 镜头信息排进照片留白；面向摄影爱好者与专业摄影师，有海外版与多端（桌面 + 移动）。闭源、订阅 / 买断制（PRD 记载终身约 $32.99，**不确定**）。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 内置风格模板按类别组织（白边 / 拍立得 / 胶片 / 杂志 / 技术铭牌等），数量约百套级（不确定）；模板是产品主资产 |
| 排版与水印 | EXIF 字段（机型 / 镜头 / 光圈 / 快门 / ISO / 焦距 / 时间）可组合；文字字体 / 颜色 / 字号 / 位置可调；留白比例可调 |
| 品牌徽标或 Logo | 内置相机 / 镜头厂商徽标用于排版（商标使用存在争议）；是否支持自定义 Logo 图片不确定 |
| 导出 | JPEG 为主（可能含 PNG），分辨率档位可选；批量能力与平台相关（不确定） |
| 编辑交互 | 预览区点选文字 / 徽标、拖拽移动、双指缩放旋转；参数以滑杆 + 下拉为主 |
| 离线与云 | 本地渲染为主；可能有账号与模板云同步（不确定），部分模板可能需登录解锁 |
| 收费模式 | 免费基础 + 订阅 / 终身买断；档位与价格不确定（截至 2024 年知识） |

- **交互与视觉拆解**：信息层级 = 大预览为绝对主角，参数收在侧栏 / 底栏；排版风格 = 中性黑白灰、模板缩略图墙；留白处理 = UI 不抢照片，模板缩略图统一比例；动效克制（不确定）。
- **可借鉴点**：(1) 模板墙「风格分类 + 一图一模板」的浏览节奏；(2) EXIF 字段组合预设（如「机型 + 参数」「纯机型」「时间 + 地点」）；(3) 一个模板 = 一次点击的最短路径；(4) 免费 / 付费边界的呈现方式（我们全免费，可作为对照卖点）。
- **与 FrameGeist 的差异**：我们 MIT 开源、全功能免费、离线无账号、模板可自制 / 导入导出、CLI 目录批处理、引擎确定性渲染与跨端像素一致；对方闭源订阅、无 CLI、模板不可自制（不确定）、存在账号与云端依赖。

### 1.2 今日水印相机

- **定位与目标用户**：工作场景的「证据型水印相机」——时间、地点、经纬度、天气、项目名、备注；面向施工 / 巡检 / 物业 / 销售外勤 / 考勤打卡与个人记录。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 场景化水印模板（打卡 / 巡检 / 工程 / 物业 / 促销 / 学习等），数量大、更新快，按行业与用途分类 |
| 排版与水印 | 水印**压在照片像素上**；大字号高对比；字段一键开关（时间 / 地点 / 经纬度 / 天气 / 自定义） |
| 品牌徽标或 Logo | 企业 / 团队 Logo 上传、团队统一水印（管理端配置） |
| 导出 | JPEG；水印图与原图是否双份保留不确定；批量加水印不确定 |
| 编辑交互 | 拍后拖动 / 缩放文字、切换模板、字段开关；偏「拍完即用」而非精修 |
| 离线与云 | 需定位权限；团队 / 考勤数据上云，账号体系强绑定 |
| 收费模式 | 免费 + 个人会员 + 企业版按人 / 年（价格不确定） |

- **交互与视觉拆解**：信息密度高，视觉完全服务于「可读性 + 不可篡改」；留白几乎不考虑；工具化配色（蓝 / 橙强调色）；模板缩略图即真实效果图。
- **可借鉴点**：(1) 场景化模板命名与分类（回答「谁在什么场合用」）；(2) 字段一键开关的紧凑面板；(3) 批量给一组照片套同一水印；(4) 时间 / 地点自动填充的失败降级（无定位时显示占位而非空白）。
- **与 FrameGeist 的差异**：红线相反——我们要求文字**不得覆盖照片像素**，只落在留白 / 边框区；对方依赖账号 / 云 / 定位，我们零上传；我们做摄影审美排版，不做证据防篡改与考勤管理。

### 1.3 白框相机

- **定位与目标用户**：极简白边 / 画框相机，卖点是「一键给照片加高级感留白 + 少量文字」；面向社交分享用户与文艺风用户。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 少而精：白边、宽边、拍立得、胶片齿孔、圆角等；分类简单（不确定） |
| 排版与水印 | 文字常在底部或右下，字号偏小、可选字体 / 颜色 / 对齐；无 EXIF 字段体系 |
| 品牌徽标或 Logo | 基本无厂商徽标库；可能有自定义签名 / 文字水印 |
| 导出 | JPEG，尺寸 / 清晰度档位；高清导出可能付费（不确定） |
| 编辑交互 | 大预览 + 底部横向工具条；点选文字拖动、双指缩放旋转、左右滑切换模板 |
| 离线与云 | 纯本地为主，可能无账号 |
| 收费模式 | 免费 + 内购 / 订阅（去广告、解锁模板 / 高清，价格不确定） |

- **交互与视觉拆解**：极简、低饱和、弱化 UI 存在感；留白比例是核心卖点（默认值经过审美调校，「打开即好看」）；动效轻、单一主操作（保存）。
- **可借鉴点**：(1) 默认参数的美学——用户只做微调；(2) 横向滑动切换模板的单手操作；(3) 界面元素极少、主操作唯一。
- **与 FrameGeist 的差异**：我们有 192 套模板 / 25 分类、EXIF 字段模板化、75 项徽章库、拼贴、CLI 与桌面端；对方无字段体系、无批量、无离线安装包，模板量级小。

### 1.4 拼图酱

- **定位与目标用户**：拼图 / 海报 / 图文排版 App；面向社媒内容创作者、微商、学生；场景 = 多图拼贴、长图、海报、九宫格。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 拼图布局 + 海报模板 + 素材商店（贴纸 / 背景 / 字体），按用途分类，瀑布流浏览 |
| 排版与水印 | 文字框、贴纸、圆角、阴影、背景；排版自由度高、依赖素材 |
| 品牌徽标或 Logo | 以贴纸 / 水印形式出现，无厂商徽标体系 |
| 导出 | JPEG / PNG，尺寸与清晰度可选；批量不确定 |
| 编辑交互 | 图层式点选、拖拽缩放旋转、层级调整、对齐辅助（不确定） |
| 离线与云 | 素材需在线下载 / 账号，部分云同步 |
| 收费模式 | 免费 + 会员（素材 / 去水印 / 高清，价格不确定） |

- **交互与视觉拆解**：高信息密度、彩色素材、模板缩略图瀑布流；版式偏「内容消费」节奏（标题 / 副标题 / 信息条）。
- **可借鉴点**：(1) 素材 / 模板面板的分类与「最近使用」；(2) 图层操作手柄与层级反馈；(3) 海报模板的版式节奏；(4) 一键换布局不改内容。
- **与 FrameGeist 的差异**：我们摄影向（EXIF + 边框 + 水印）、素材随包、无账号；拼图我们已有（网格 + 自由拼贴），但布局数量与素材丰富度不及，且我们不做贴纸商店。

## 2. 国际 4 家

### 2.1 VSCO

- **定位与目标用户**：摄影社区 + 滤镜 / 编辑 App；面向有审美诉求的摄影用户与内容创作者，卖点是胶片质感预设与社区分发。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 滤镜预设（Film 系列）+ 编辑「配方 Recipe」（可保存 / 复用 / 分享） |
| 排版与水印 | 有画布 / 边框（Canvas / Border）能力：白边或彩色边、比例与背景；具体档位不确定 |
| 品牌徽标或 Logo | 无 |
| 导出 | JPEG，尺寸 / 质量可选；会员支持批量编辑 / 批量导出（不确定） |
| 编辑交互 | 滑杆参数、长按对比原图、双击收藏预设、手势缩放 |
| 离线与云 | 本地编辑 + 账号 + 云同步 / 社区发布 |
| 收费模式 | 免费基础 + 会员订阅（约年付十几到二十几美元，不确定） |

- **交互与视觉拆解**：极简黑白 UI、照片优先、参数面板低干扰；社区流以图为主，编辑页把预设放在最前。
- **可借鉴点**：(1) 配方 / 预设的保存与复用（对应我们的导出预设与「我的模板」）；(2) 长按对比原图；(3) 会员价值呈现（免费可用、付费进阶）——我们全免费，可反衬差异。
- **与 FrameGeist 的差异**：我们不做调色滤镜、不做社区、不做账号；我们做确定性模板渲染、本地批处理与 CLI 自动化。

### 2.2 Adobe Lightroom（移动端）

- **定位与目标用户**：专业级移动修图与照片管理；面向摄影师与进阶爱好者，移动端是采集 / 初修入口，与桌面 / 云打通。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 官方 / 社区 / 用户预设（Presets），可云端同步与分享（桌面互通） |
| 排版与水印 | 导出水印（文本或图形 Logo，位置 / 大小 / 不透明度）；不做边框排版模板 |
| 品牌徽标或 Logo | 水印图片自定义上传，无内置厂商库 |
| 导出 | JPEG / PNG / TIFF / DNG（移动端以 JPEG 为主）；尺寸 / 质量 / 色彩空间 / 元数据选项；支持批量导出与「同步设置」 |
| 编辑交互 | 蒙版与滑杆、长按对比、手势缩放、批量粘贴设置 |
| 离线与云 | 本地编辑可用；云同步与云端 AI 需订阅与联网 |
| 收费模式 | 免费基础 + Premium 订阅（约 $4.99/月 或与 Creative Cloud 捆绑，不确定） |

- **交互与视觉拆解**：深色专业界面、参数分组折叠、以数值 + 滑杆为主；移动端弱化装饰、强调效率与一致性。
- **可借鉴点**：(1) 导出设置分组与「导出预设」（尺寸 / 质量 / 水印 / 元数据一次配置）；(2) 批量「同步设置」到多张；(3) 长按对比；(4) 水印的位置 / 大小 / 不透明度三参数模型。
- **与 FrameGeist 的差异**：对方是像素级调色 + AI + 云；我们是排版层（边框 / 水印 / 拼图）+ 离线确定性渲染 + CLI；我们无账号、无云、无 AI。

### 2.3 Photoroom

- **定位与目标用户**：AI 商品图 / 电商图编辑；面向电商卖家、小商家、社媒运营；核心 = 抠图、背景替换 / 生成、批量出图。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 商品图 / 社媒尺寸模板，一键套用；模板与「结果导向」绑定 |
| 排版与水印 | 文字 / 形状 / 水印；品牌 Logo 可批量加；排版偏商品图逻辑 |
| 品牌徽标或 Logo | Brand Kit：Logo / 颜色 / 字体，团队共享 |
| 导出 | JPEG / PNG，社媒尺寸预设，批量导出（付费档），另有 API 批量 |
| 编辑交互 | 点选对象、AI 一键操作、图层式编辑（文本 / 图片 / 形状）、拖拽 |
| 离线与云 | 云为主（AI 需联网）；有 Web / 移动 / API |
| 收费模式 | 免费 + Pro 订阅（约 $9.99/月，年付更低，不确定）+ 团队 / 企业 + API 按量（不确定） |

- **交互与视觉拆解**：明亮、卡片式、模板缩略图大而醒目；强调 before / after 对比与「一键完成」。
- **可借鉴点**：(1) Brand Kit 的「品牌包」概念（Logo / 颜色 / 字体统一管理）；(2) 社媒尺寸一键多尺寸导出；(3) 批量导出与命名；(4) API / 自动化（对应我们 CLI 的差异化补强）。
- **与 FrameGeist 的差异**：我们不做抠图 / 生成式 AI、离线无账号；但「品牌包 + 批量 + 多尺寸」是可直接吸收的交互范式。

### 2.4 Canva

- **定位与目标用户**：在线平面设计（模板 + 拖拽编辑器）；面向非设计师（营销、教育、个人）。
- **功能矩阵**

| 维度 | 观察 |
|---|---|
| 模板体系 | 海量模板；分类 / 搜索 / 收藏 / 最近使用 / 推荐；模板详情含作者与相关推荐 |
| 排版与水印 | 完整文字工具（字体 / 字号 / 行距 / 字距 / 对齐 / 效果）、对齐参考线、位置与图层面板 |
| 品牌徽标或 Logo | Brand Kit（付费：Logo / 配色 / 字体 / 品牌模板） |
| 导出 | PNG / JPG / PDF / SVG / MP4 等；尺寸与质量；批量导出（付费）；一键多尺寸（Magic Resize，付费） |
| 编辑交互 | 点选 / 拖拽 / 对齐吸附 / 快捷键 / 右键菜单 / 实时协作 |
| 离线与云 | 云为主、账号必需；协作与评论 |
| 收费模式 | 免费 + Pro 订阅（约 $12.99/月 或 $119.99/年，不确定）+ 团队版 |

- **交互与视觉拆解**：强引导（首页即模板推荐）、彩色卡片化；编辑器左素材 / 右属性 / 顶部工具条；空状态用模板填补。
- **可借鉴点**：(1) 模板墙「搜索 + 分类 + 收藏 + 最近」四件套（我们缺收藏）；(2) 对齐参考线与图层 / 位置面板；(3) 键盘快捷键与速查入口；(4) 导出命名与多尺寸；(5) 模板详情（作者 / 分类 / 相关推荐）。
- **与 FrameGeist 的差异**：通用设计工具 vs 垂直摄影工具；我们离线优先、无账号、无协作；模板与素材量级无法比，但我们在 EXIF / 边框 / 拼图 / CLI 上更深。

## 4. 我们可吸收的结论（10 条）

1. **C1 导出预设（VSCO Recipe / Lightroom Export Preset）**：竞品把「尺寸 + 质量 + 水印 + 元数据」打包成可命名、可切换的预设；我们目前只有设置页里的默认值，缺「一套配置一次点选」。→ 对应提案 P1。
2. **C2 批量导出的命名规则（Photoroom / Lightroom / Canva）**：批量出图后文件名是真实痛点；我们只有重名去重（`uniqueName`），缺模板化命名与预览。→ 对应提案 P2。
3. **C3 快捷键与速查表（Canva / Lightroom）**：我们的快捷键集中在方向键 / 撤销 / Esc / 空格平移；缺「导出、适应窗口、100%、图层切换、快捷键速查」等高频动作。→ 对应提案 P3。
4. **C4 模板收藏（Canva 四件套）**：我们已有模板搜索与「最近使用」，缺收藏与自定义集合；品牌库已有收藏 / 最近，可复用同一交互模式。→ 对应提案 P4。
5. **C5 品牌包 Brand Kit（Photoroom / Canva）**：把徽标 + 水印 + 文字默认值 + 导出配置打包成可切换的「品牌包」，服务工作室 / 多品牌用户。→ 对应提案 P5。
6. **C6 留白可视化与「打开即好看」（白框相机 / VSCO）**：v1.0.0 Step 3 的自动拟合是引擎能力，编辑器里还需把「检测到的留白区 + 2/3 拟合框」画出来，否则用户看不懂引擎在做什么。→ 对应提案 P6。
7. **C7 长按对比原图（VSCO / Lightroom）**：极低成本、极高感知，帮助用户判断边框 / 水印是否喧宾夺主。→ 对应提案 P8。
8. **C8 一键多尺寸导出（Photoroom / Canva Magic Resize）**：分享要 2K、归档要 4K / 原图；现在需要重复操作两次。→ 并入提案 P1。
9. **C9 场景化模板入口（今日水印相机 / Canva）**：模板墙除「风格分类」外，可按用途 / 场景给入口（朋友圈 / 小红书 / 存档 / 客户交付），降低选择成本。→ 并入提案 P5 与模板墙文案。
10. **C10 粘贴 / 拖拽导入与落点（Canva / Lightroom）**：我们有 dropzone 与拖拽套模板，但缺 Ctrl+V 粘贴与「拖到画布落点」。→ 对应提案 P7。

> 反向结论（**不吸收**）：账号 / 云 / 协作、生成式 AI 抠图、滤镜调色、素材贴纸商店、把水印压在照片像素上——均与本项目红线（零上传 / 离线 / 文字不遮照片 / 不引入运行时框架）冲突，明确排除。
