## 3. 技术设计规范

### 3.1 徽标颜色系统（P1/Q1–Q3）

**判定规则（附录 B 伪代码）**：hex→HSL；`s ≥ 0.18 且 0.10 ≤ l ≤ 0.90` → 彩色品牌；否则单色。规则一次执行后把**最终品牌清单**（含每品牌 hex 与判定结果）锁进 `tools/brand-colors.json` 并写入 `docs/reports/v0.9.0/brand-color-report.json`，作为可审查快照（后续要改只允许追加白名单/黑名单覆盖项）。

**变体命名（禁止破坏旧引用）**：

| 文件 | 语义 |
|---|---|
| `brand/<slug>.png` | **主变体**：彩色品牌 = 官方 hex 彩色；单色品牌 = 黑（与 v0.8 相同路径） |
| `brand/<slug>-mono.png` | 黑色单色变体（新增） |
| `brand/<slug>-light.png` | 白色变体（沿用） |
| `*/thumbs/<slug>[-mono|-light].png` | 96px 同源缩略图（彩色品牌主变体为彩色） |

- `lockup/` 同规则（同品牌同色）；`series/`、`game/` 仍黑/白两版。
- 引擎解析（`render.rs`）：默认加载主变体；按徽标区域背景对比度评估——彩色不达标 → 回退 `-mono`/`-light`（按背景选）；仍不达标 → 沿用现有描边/底板逻辑。显式 `tint: "color"` 强制彩色；`tint: "auto"`（默认）执行上述回退；现有 5 种手动模式保留并新增 `color`。
- 库/墙标记缩略图：彩色品牌显示彩色（明暗主题一致）；单色品牌亮色主题用黑、暗色主题用 `-light`。
- `web/brand/index.json` → **version 3**：每项 `{slug, label, official, color:"#rrggbb"|null}`（v2 字段保留，读取兼容 v2）。
- 资产门禁：新增 `tools/check-brand-colors.mjs`——校验变体矩阵文件齐全、彩色品牌主变体存在高饱和像素、单色品牌主变体无饱和像素、manifest `color` 与生成器一致。

### 3.2 徽标尺寸（P2/Q4）

- 引擎：`0.05→0.06` 下限（仍 ≥18px）、默认层高 `0.045→0.065`、最大宽 `0.38→0.44`。
- `tools/apply-v090-typography.mjs`（幂等标记模板 `version 1.3.0`）：
  - 徽标层（brand/lockup/series/game/user）`height × 1.3`，上限 0.12，结果 <0.06 抬到 0.06；原 ≥0.10 保持；
  - 沿用 v0.8 越界/重叠守卫（跳过旋转层），超限按 1.3→1.15→1.0 回退并记录；
  - 报告 `docs/reports/v0.9.0/typography-report.json`。
- 模板 `version` → **1.3.0**；`minEngineVersion` 保持 **0.7.0**（无新 schema 字段）。
- `engine_v070.rs` 断言改新数值并新增「6.5% 默认高」「44% 最大宽」「6% 下限」用例。

### 3.3 侧边栏 Tab 重构（P3/Q9–Q11）

- 结构：`.sidebar` = 固定 Tab 头（5 个：**模板 / 照片 / 元素 / 画布 / 导出**）+ 单一滚动面板 + 底部紧凑导出条；Tab 选择持久化 `fg-sidebar-tab`；默认「模板」。
- Tab 内容映射（附录 D）：模板（模板选择/拼图布局）；照片（拖放/示例/文件信息/EXIF 文字与信息）；元素（添加元素含徽标库/图层/元素属性/文字样式预设/水印/微调）；画布（比例/背景/边距/圆角阴影/相框/裁剪）；导出（尺寸/格式/质量/元数据/批量/更新）。
- 底部导出条：单行 ≤56px，含「渲染预览」+「导出」+ 尺寸/格式摘要（点击弹出选择）；**不再 sticky 覆盖内容**（作为 grid 行参与布局或 `position:static` 于滚动面板之后）。
- 布局硬指标（E2E 断言）：任一可见侧栏区块两两不相交（重叠面积 0）；导出条不遮挡内容（内容区底部 ≤ 导出条顶部）；1440×900 下无横向滚动。
- 移除 tier：`LS_TIER`/`setTier`/`toggleTier`/`#tierToggle`/`#panelTierBtn` 及 `advanced-only` 逻辑删除；旧 localStorage 静默忽略。

### 3.4 i18n 全覆盖（P4/Q11）

- **属性标签**全部改 i18n key（`props.*`）：`offset.x→水平偏移`、`offset.y→垂直偏移`、`z→层级`、`rotation→旋转`、`opacity→不透明度`、`font.size→字号`、`letterSpacing→字距`、`lineHeight→行高`、`align→对齐`、`font.color→文字颜色`、`effects.case→大小写`、`stroke.width→描边宽度`、`stroke.color→描边颜色`、`fill→填充`、`relief→立体`、`shadow→外阴影`、`size→尺寸`、`view→视图`、`accent→强调色`、`insert.preset→文字样式预设`、`autoHide→自动隐藏`、`layout.frame→布局框` 等（完整表在实现时补全并过扫描）。
- **图层名**：新增 `layerDisplayName(layer)`：
  - 用户重命名优先；
  - 徽标/图片层 → 「徽标」+ 资产标签（如「徽标 · Canon」）；用户上传 → 「自定义图片」；
  - 文本层按内容/表达式角色 → 机型/镜头/参数/日期/星期/坐标/富士配方/自定义文字；无法判定 → 「文字」；
  - 形状 → 线框/分割线；色卡 → 色卡；日历 → 日历；组 → 组。
  - 表达式预览不再是主标签（可作 title 提示）。
- **门禁升级** `tools/check-i18n.mjs`：
  - 扫描新增：`addDual/addSelect/addCheck/addColor(grid, "<label>"...)` 首个字面量必须是已存在的 i18n key；
  - 扫描范围含 `editor.js` 新建 DOM 文案；zh/en 键对齐维持 0 failure。
- **E2E 中文残留扫描范围**扩至：全部 5 个 Tab 可见文本 + `#propsBody` + `#layerList` + 添加元素区（白名单沿用附录 B v0.8 词表 + 字体族名 + 品牌名）。
- 术语表新增（附录 A）同步进 `docs/DESIGN-LANGUAGE.md`/`TEMPLATE-SPEC.md` 若涉及。

### 3.5 画布直接操作（P5/Q12–Q15）

- **选择**：`pointerdown` 命中（自上而下）；已选集内再点穿透到下层；Shift 点击追加/移除；空白点击清空；选中态 = 主色描边框 + 手柄。
- **拖移**：沿用现 `beginDrag("move")` + 吸附参考线（保留）；指针离开元素仍可拖（pointer capture）；拖拽期间实时预览、`pointerup` 一次入历史（沿用 `history:false` + `commitNow`）。
- **缩放**：四角手柄（nw/ne/sw/se），拖拽等比缩放，语义（Q13）：text→`font.size`（clamp 0.002–0.5）；image/badge/palette/calendar/group→`size` 等比（palette 用 `size` 标量）；line/shape→`size.width/height` 等比、线段仅长度+粗细；最小尺寸守卫（≥2 屏幕 px）。
- **旋转**：顶边上方 24px 手柄，文本/形状可用；15° 吸附（±4°）、Shift 自由；写 `rotation`。
- **删除**：Delete/Backspace（输入焦点不在控件时）+ 浮动工具条按钮；删除走 `edit()`（入历史）。
- **浮动工具条**：选中即显示于选区上方（屏幕坐标，随缩放/平移重算）：删除 / 复制 / 锁定 / 置顶 / 置底；图标按钮 + `aria-label` + `title`（i18n）。
- **手柄实现规范**（Q14）：容器 `.handle` 视觉 10px 圆点（`::after`），命中区 24×24 隐形（`width:24px;height:24px;background:transparent` 且圆点居中）；`touch-action:none`；`@media (pointer:coarse)` 14px/32px；cursor 按方位（nwse/nesw + `grab` 旋转）；手柄渲染在独立 overlay 层（`.edit-overlay`，不受 canvas 缩放影响视觉尺寸——命中区为**屏幕像素**）。
- **不改动**：裁剪（crop）与自由拼图（free collage）现有覆盖层交互路径原样保留，只新增 frame-mode 图层手柄；避免回归。
- **舞台导航**（Q15）：`fitStage` 保留；新增「适应窗口/100%」切换、缩放下拉（50/75/100/150/200%）、选中自动平移入视野（平滑、尊重 `prefers-reduced-motion`）、空格/中键平移、状态栏画布尺寸 `W×H px`。
- 键盘保持：方向键微调（1px/Shift 10px）、Ctrl+Z/Y、Esc 取消选择/退出裁剪。

### 3.6 徽标库集成与筛选（P6/P7/Q5–Q8）

- **筛选修正**：`renderLibGrid(grid, items, ...)` 接收**已过滤的条目**；`renderBrandLibrary()` 按 `brandLibState.group`（"all" | 四组）过滤后再传；chips = 全部 + 四组（单选，`.on` 状态）；搜索在**当前分组内**过滤（group=all 时跨组）；收藏/最近为独立快捷行（点击应用，不改变分组）。

## 4. 任务分解（M0–M6 顺序执行）

### M0 — 资产与引擎颜色系统
1. `tools/gen-brand-assets.mjs`：采集官方 hex（用 `cdn.simpleicons.org/<slug>` 或 simple-icons 数据），执行阈值规则，输出主变体（彩色/黑）+-mono/-light + 三套 96px thumbs；生成 `tools/brand-colors.json` 锁定清单；更新 `CREDITS.json`（hex 来源 + 判定）与 `docs/CREDITS.md`。

## 8. 回退预案

1. 阈值规则产生个别品牌色观感不佳 → 只允许用 `tools/brand-colors.json` 的 `monoOverride` 名单覆盖，并在报告写明理由（不改规则代码）。
2. 引擎彩色回退带来性能回归（徽标分析开销）→ 仅对主变体为彩色的徽标做分析，结果缓存于渲染上下文；仍不达标则 `tint:"auto"` 直接按背景取黑白（记录）。
3. 手柄/工具条与既有 E2E 选择器冲突 → 保持 overlay 结构（`.edit-overlay/.box/.handle`），新增类名不替换旧类名；crop/free-collage 路径零改动。
4. Tab 重构导致个别 E2E 找不到元素 → 仅改探针（选择器尽量不变），断言数目不减；不得为过测试而删断言。
5. 图片缩放语义引发模板盒异常 → 缩放仅写 `size`，越界自动回退（同款守卫）并记录。
6. 视觉基线差异过大人工不可审 → 输出「单模板 before/after + 差异说明」到报告，再重生成。
7. API 推送失败（限流/权限）→ 重试；仍失败先本地 tag + 报告，不阻塞 Pages/Release 之外工作。

## 10. 附录 B：彩色品牌判定伪代码（锁定规则）

```js
function isColorful(hex) {
  const [r, g, b] = [0, 2, 4].map((i) => parseInt(hex.slice(i, i + 2), 16) / 255);
  const max = Math.max(r, g, b), min = Math.min(r, g, b);
  const l = (max + min) / 2;
  const s = max === min ? 0 : l > 0.5 ? (max - min) / (2 - max - min) : (max - min) / (max + min);
  return s >= 0.18 && l >= 0.10 && l <= 0.90; // 彩色品牌
}
// 输出锁定：tools/brand-colors.json = { hex, colorful, monoOverride: [] }
```

> 预期示例（实现时以实际抓取为准并锁表）：Canon/Nikon/Fujifilm/Leica/Sigma/Zeiss/Tamron/Samsung/Nokia 等彩色；Sony/Apple/DJI/GoPro/Hasselblad/Blackmagic 等黑/白保持单色。

## 11. 附录 C：变体解析与回退链

```
@builtin/brand/<slug> → brand/<slug>.png（主变体）
  tint=auto:   主变体对比不足 → -mono / -light（按背景亮度） → 仍不足 → stroke/plate
  tint=color:  强制主变体（若主变体为彩色）
  tint=light/dark/stroke/plate: 现有语义不变
@builtin/lockup/<slug> → lockup/<slug>[-mono|-light].png（同链）
@builtin/series|game/<slug> → 黑白两版（不参与彩色）
优先级（属性）：图层字段 > 模板级 override > 模板 JSON
```
