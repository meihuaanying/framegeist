## 2. 任务 T2：边框水印文字艺术（8 风格 + 字效矩阵）

**原则**：功能对齐 frameelf，视觉 100% 原创。**不得**复刻其模板版式参数、命名、文案。

### 2.1 排版底座
- 升级到 `cosmic-text 0.19`（HarfRust shaping）+ `swash`（字形轮廓/可变字体轴/栅格）。
- 必须支持：kerning、连字、字重选择、字形轮廓输出（供字效做掩膜）。
- 保留 `--legacy-text-renderer` 回退开关（引擎配置 + 测试锁两路径输出一致或明确差异）。
- 跨端一致：CLI/WASM/桌面同输入像素一致（沿用现有字节一致门禁）。

### 2.2 字效矩阵（全部落地、可组合、全部有像素断言）
| 组 | 能力 | 实现要点 |
|---|---|---|
| 描边 | 外描边/白边/双线/描边粗细/描边颜色 | 字形掩膜形态学膨胀真外扩；双线=内外两圈 |
| 立体 | 压印/浮雕/内阴影/外阴影（偏移/模糊/不透明度） | 偏移高光+阴影；阴影可关（低配提示） |
| 材质 | 烫金/渐变/纹理填充/箔高光 | 渐变/噪声纹理 × 字形掩膜；镜面高光条 |
| 布局 | 分割线（两侧无元素自动隐藏）/对向边框/外边框/按内边距显示 | 线型层自动测量邻居 |
| 尺寸 | 基础宽度/高度、自适应宽度/高度、同时调整两端、填满页面 | 文本量→尺寸求解 |
| 文字 | 首字母大写/全大写/全小写、字重、字间距、行间距、缩放、旋转、翻转 | cosmic-text 属性 + 后处理 |
| 位置 | 位置/上-下/左-右/垂直对齐/水平对齐/层级 | 沿用九宫格 + 图层序号 |
| 徽章 | Logo 徽章行/自适应高度/自动明暗变体 | 已有能力强化 |

### 2.3 八款自创艺术风格（每款 ≥1 套模板 + 编辑器内可选"文字样式预设"）

## 4. 技术决策与风险

- **wasm 体积不限**；但性能门禁不变：24MP 预览 ≤600ms、导出 ≤2s；60MP 预览 ≤1.5s、导出 ≤4s。
- cosmic-text 已实测 wasm32 编译通过（raw 基线 2.75MB）。若集成后性能/体积恶化到破坏门禁：回退路径 = `swash` 直接用（shape + outline + scale），保持排版质量；再保底 = `rustybuzz` + 现有栅格。
- 黄历算法：公历→农历用成熟查表/寿星公式自实现；无数据的宜忌/神煞**不显示**，绝不编造。
- 相框空白检测：对 PNG alpha 通道做行/列扫描取最大内接矩形（含容差）；测试覆盖空心/偏心/多孔三类。
- 照片自动匹配：Picsum 全量 ID 池（≥1000）；不足时用程序化渐变艺术照补齐（仍保证唯一）。
- 任何模块未达标不得跳过去做发布门禁；宁可延长工期，不缩水。
