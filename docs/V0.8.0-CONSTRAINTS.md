## 1. 红线（v0.7 之上新增）

- 沿用：零上传 / 0 账号 / 离线可用 / GPS 默认剥离 / 不引入商业字体 / 不碰 `D:\FrameLoom`。
- **禁止用 PowerShell `Set-Content/Out-File` 改写含非 ASCII 的仓库文件**（v0.6.1 事故铁律）；统一 Edit 工具或 Node 脚本；发布前必跑 `node tools/check-utf8.mjs`。
- **禁止修改 `.github/workflows/*`**（推送会被 404）；发布说明用 `gh release edit --notes-file` 注入。
- 品牌资产红线：官方图形仅来自 Simple Icons（CC0）或原创排版；**不描摹官方图形**；商标免责声明保留。
- 兼容红线：v0.7 全部能力（EXIF 直通/ICC/AVIF/WebP/HEIC/自由拼图/模板墙/灯箱/批量）不得回归；WASM↔CLI 帧字节一致保持。
- 中文 UI 不得引入机器翻译痕迹；固定术语（图层/画布/徽标/导出/比例）按本文件附录词表。

## 2. 任务分解（M0–M5 顺序执行）

### M0 — UI 全量中文化 + i18n 门禁

1. `web/i18n.js`：
   - 新增 `layer.type.text/shape/image/group/palette/calendar`、徽标库全部文案、启动提示、收藏/最近、空态/提示语；
   - 全量排查 `web/app.js`、`web/editor.js`、`web/index.html`：`textContent`/`insertAdjacentText`/`title`/`aria-label`/`placeholder`/`toast()`/错误码文案必须走 `t()`；
   - `localizeEngineError` 覆盖引擎全部 `code()`（缺一补一）；日期/语言相关 UI 文案与 `currentLang()` 一致。
2. 新增 `tools/check-i18n.mjs`：
   - zh/en 键集合完全一致（缺失/多余都失败）；
   - 扫描 web/*.js|html 中「直接赋值的用户可见字符串」模式（`textContent = "..."`、`title = "..."`、`placeholder="..."`、`aria-label="..."`、`toast("...")`、`alt="..."`）中的中文或英文句子，白名单正则见附录；
   - 退出码 0/1，可挂 CI。
3. E2E 新增：切到中文 → 扫描可见 UI 文本英文残留（白名单外出现 ≥3 连续拉丁字母即失败）；覆盖墙/编辑器/设置/灯箱。

### M1 — 徽标库（资产 + 数据 + UI + 图层级替换）

1. 资产管线 `tools/gen-brand-assets.mjs`：
   - 输出 `<dir>/<slug>[-light].png`（512）与 **`<dir>/thumbs/<slug>[-light].png`（96）**；
   - 生成**中性「EXIF」原创标**（`brand/exif-auto`）用于表达式模板的卡片标记；
   - 生成清单 `web/brand/index.json` 升级为分组结构：`{version:2, groups:{camera:[],lens:[],series:[],game:[],custom:[]}, counts:{...}}`（保留旧数组读取兼容一版）。
2. 数据：库里每项 `{slug, group, hasOfficial:boolean, label}`；标签为品牌原文名（白名单专有名词）。
3. UI（`index.html` + `app.js`/`editor.js` + `styles.css`）：
   - 卡片「徽标库」置于右侧栏（替换原 brandCard）；结构 = 风格开关（官方/原创，沿用）+ 搜索框 + 分组 tabs + 收藏/最近 chips + 网格（96px 懒加载 + content-visibility）+ 顶部「自动识别（EXIF）」+「显示徽标」开关 +「上传自定义」；
   - 暗色自动用 `-light` 缩略图；选中态/收藏星标；
   - **点击行为**：对「目标图层」做替换（`selectedLayerId`；无则第一个徽标层并 toast 提示）；写入 per-template layer edits（`fg-tpl-edits-v1` 扩展 `asset` 字段）；「自动识别」清编辑恢复表达式；
   - 风格开关联动：表达式层换 kind；实体层 brand↔lockup 互换；
   - 移除全局 brandOverride UI/状态；`ensureBuiltinAssets` 改为按模板+编辑后的资产路径注册（含 lockup/thumbs 不需要注册缩略图）。
4. 模板墙：顶栏「徽标库」入口弹层（只读浏览 + 风格开关 + 分组 + 搜索 + 「进入编辑器替换」按钮）；卡片右下角品牌标记（≤3 枚 96px，表达式层显示 `exif-auto`）。
5. 收藏/最近：`fg-brand-fav-v1` / `fg-brand-recent-v1`（localStorage），最近最多 12。

### M2 — 默认尺寸提升（引擎 + 模板 + 测试）

1. 引擎（`render.rs`）：下限 `0.035→0.05`（仍 ≥18px）；默认层高 `0.03→0.045`；最大宽 `0.32→0.38`。
2. 脚本 `tools/apply-v080-typography.mjs`：
   - 幂等标记 `meta.version==1.2.0` 跳过（`--force` 重放）；
   - 角色判定沿用 v0.7 规则：Data/Label ×1.2、Support ×1.1、Display 不变；乘后仍 ≥0.0095；
   - 徽标层（brand/lockup/series/game/user）`size.height` 抬到 ≥0.045；
   - **越界/重叠保护**：逐模板用引擎 `layer_boxes`（CLI 或 wasm harness）计算文本盒；若文本盒超出画布或同区文本盒 IOU/垂直重叠超阈值 → 该层按 1.1→1.0→原值回退，记录到报告；
   - 输出改动清单（每模板每层 before→after）到 `docs/reports/v0.8.0/typography-report.json`。
3. 测试更新：`engine_v070.rs` 尺寸下限断言改 5%/默认 4.5%/最大宽 38%；新增徽标默认尺寸断言。

## 5. 回退预案（不可行时按此执行并记录，不阻塞整体）

1. 越界/重叠回退不收敛（个别模板）→ 保留原字号并标注 `v080-scale:reverted`，人工审对比图确认。
2. 96px 缩略图体积失控（>5MB）→ 降为 64px 或改用 CSS 缩放（记录）。
3. 分组资产缺失（如游戏组某 slug 无字标）→ 隐藏该项不造假。
4. 中文残留扫描误报 → 扩充白名单并记录依据（只加专有名词/技术缩写，不加普通英文词）。
5. content-visibility 引发滚动跳动 → 补 `contain-intrinsic-size: auto` 或移除该规则（保留 lazy）。
6. API 推送失败（限流/权限）→ 重试；仍失败则先本地 tag + 报告，不阻塞 Pages/Release 之外的工作。
7. 桌面首启仍被系统扫描拖慢 → 状态提示保持 8s/25s 分级，不改二进制。
