## 2. 技术选型（已调研，落地判据）

| 能力 | 选型 | 判据 / 注意 |
|---|---|---|
| EXIF 注入样片 | `img-parts`（Rust）容器级 APP1 读写，**不重编码像素** | 注入后 `probe` 全字段可读；样片像素哈希不变 |
| EXIF 字节直通导出 | `img-parts` + 自定义 TIFF IFD 手术（去 GPS IFD 0x8825、去序列号 0xA431/0xA435、去 OwnerName 按红线） | 导出文件 `probe`：MakerNote/Fuji 配方保留、GPS/序列号为空；畸形 EXIF fuzz 零 panic |
| ICC 色彩 | `moxcms`（纯 Rust、wasm 友好）；解码时按源 ICC 转换为 sRGB 数值、导出标注 sRGB | 决策理由：绘制色与文字色基于 sRGB，直贴源 ICC 会造成二次误配；WYSIWYG=数值正确 + 标注正确。Display P3 样片像素断言（转换前后色差可解释） |
| 排版特性 | cosmic-text `Attrs::font_features`（`tnum`/`lnum` 数字、`smcp`/`c2sc` 小型大写） | 模板文本层新增可选 `features:["tnum"]`；字体不支持时无副作用（渲染像素断言对照） |
| 日期本地化 | 引擎 `date` 表达式扩展 `fmt:"zh"｜"en"｜"iso"` 选项（默认保持现状） | zh `2026年9月16日`、en `SEP 16, 2026`、iso `2026.09.16` |
| AVIF/WebP 导出 | `image 0.25.10`：AVIF 有损（ravif 纯 Rust）、WebP 无损 | wasm ≤15MB 门禁；导出耗时记入性能表；Safari 兼容抽测 |
| HEIC 解码（Web/桌面） | `libheif-js` wasm-bundle，惰性动态 import（仅首次遇到 HEIC 时加载） | 不破坏离线（加载失败提示「需联网一次以解码 HEIC」）；40MP/256MiB 上限提示；Safari 原生路径优先 |
| wasm 性能 | `wasm-opt`（Binaryen）与 `+simd128` 评估 | **硬门禁：CLI↔WASM 帧像素仍字节一致（N2）**；不达则仅保留不做 SIMD 的 wasm-opt，再退则原样，记录原因 |
| 视觉回归 | 新建 `tools/visual-regression.mjs`：pHash（dHash 64bit）+ 平均色差双指标，基线 `tools/visual-baselines.json` | 样片变化 > 阈值即失败；`FG_UPDATE_VISUAL_BASELINES=1` 显式重生成并在报告记录 |
| Tauri/依赖升级 | 评估 tauri 2.x 最新稳定、rust 依赖小幅升级 | CI `release.yml` 锁定的 tauri-cli 版本同步；四 target 与 clippy 全绿才可合入 |

## 4. 质量门禁（DoD，全绿才可发布）

1. 引擎：每个新能力单测/像素断言；EXIF 注入与直通对畸形输入模糊测试零 panic。
2. 跨端：WASM↔CLI 帧渲染**字节一致**；拼图 ≤0.1% 像素差（SIMD 引入后必须复测）。
3. E2E：基线 160 条 + 新增 ≥15 条（示例照片入口、无 EXIF 占位、字段点选、导出提示、AVIF/WebP、HEIC fixture、ICC、EXIF 直通、视觉回归调用等），全绿且无页面错误。
4. 性能（契约 §4 不变）：24MP 预览 ≤600ms、导出 ≤2s；60MP 预览 ≤1.5s、导出 ≤4s。
5. 体积：wasm ≤15MB（含 AVIF；HEIC 惰性独立文件不计入但需记录大小）。
6. 四 target（msvc/wasm32/aarch64-linux-android/aarch64-unknown-linux-ohos）+ clippy `-D warnings` + `cargo fmt --check` 全绿。
7. 样片门禁：192/192 唯一 + EXIF 完整 + 视觉回归通过（阈值内）。
8. 许可证：`docs/licenses/` 完整（含 libheif-js LGPL-3.0 全文）；CREDITS 含三张照片署名。
9. 报告：`docs/reports/v0.6.0/`（README + PROGRESS + 对比截图 + 性能/体积数字 + 已知取舍）。

## 6. 暂停条件与回退预案

1. `incoming/` 缺少三张原图，或 EXIF 可解析字段 <5 项、方向不匹配 → **暂停并请用户补图**（例外①）。
2. wasm SIMD/wasm-opt 破坏 CLI↔WASM 字节一致且无法在同一构建开关下回退 → 保留无 SIMD 优化版本，记录 PRD Discoveries（例外③）。
3. libheif-js（LGPL-3.0）法律评估不可行 → 跳过 Web HEIC，保留「HEIC 需转换」提示，记录（例外③）。
4. AVIF/WebP 使 wasm 超 15MB → 降级为「仅 WebP」或按需惰性独立模块，记录（例外③）。
5. Tauri 升级引发 CI 无法在限定时间内修复 → 回退到 2.11.4 锁定版，记录（例外③）。
6. 三张照片含敏感信息（人脸特写/私密地点）与展示用途冲突 → 暂停向用户确认（例外①）。
