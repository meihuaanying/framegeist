## 1. 红线（在 v0.6 基础上新增）

- 沿用：零上传/0 账号/离线可用/GPS 默认剥离/不引入商业字体/不碰 `D:\FrameLoom`。
- **字体许可**：仅使用 OFL/CC0/公有领域字体；每款字体记录来源、版本、许可全文（`docs/licenses/`）与 CREDITS 条目；修改版/实例化产物沿用 OFL 并保留版权声明。
- **商标合规**：官方品牌字标仅用于「器材信息展示」用途；CREDITS 与发布说明加声明「各品牌字标/商标归其权利人所有，本项目仅作识别展示，不表示隶属或背书」。原创 lockup 不得模仿官方 logo 的图形化元素（字标排版可用，图形徽记不复制）。
- **字形覆盖**：任何模板使用字符必须存在于所选字体子集；禁止豆腐块（新增门禁工具强制）。
- 现有 API/行为兼容：徽标与字重变更不得破坏 v0.6 已发布能力（EXIF 直通、ICC、AVIF/WebP、HEIC、自由拼图等）。

## 3. 设计规范（DESIGN-LANGUAGE v2，写入 `docs/DESIGN-LANGUAGE.md` 并强制执行）

1. **字号阶梯**：以照片高度为基准的相对字号；每模板内至少 3 级（Display/Support/Detail），相邻级比 1.25–1.5（瑞士 1.25 / 编辑 1.333）。
2. **字距规则**：Display（≥0.10 照片高）紧字距 −0.02~−0.04em；小号大写（label/kicker）+0.06~+0.12em；正文/数字 0；中文标题 0~+0.02em；**EXIF 数值行用 tabular（tnum）**。
3. **行高**：Display 1.0–1.15；副标 1.2–1.35；正文/参数行 1.4–1.6；CJK 标题 ≥1.15（避免笔画相撞）。
4. **字重层次**：Display 用 600/700；副标 500；参数/标签 400–500；弱化信息用透明度而非更细字重（无 Hairline）。
5. **中英混排**：中文与拉丁/数字间不强制空格（模板字面量控制）；中文标点使用全角；参数行统一半角；冒号/间隔符统一 `·`（U+00B7）。
6. **对齐与网格**：同侧元素共享对齐线；多行左对齐优先；九宫格锚点 + 光学对齐修正（圆形字标轻微外扩）。
7. **分类风格映射**（Q18）：
   - `classic-watermark/minimal/white-border/borderless` → 瑞士国际主义（Inter/Geist、极简线、克制）
   - `magazine/master/portfolio/art` → 编辑杂志（Fraunces/Instrument Serif/Playfair 大标题 + Inter 参数行）
   - `personal/calendar/festival` → 日系排版（霞鹜文楷/思源宋、宽字距、细线框）
   - `game/colorful/colorcard/sports` → 潮牌海报（Unbounded/Bricolage/得意黑、超大字号、紧字距）
   - `camera/film/phone/drone/fuji` → 器材说明书（Geist Mono/JetBrains Mono 数据行、标签化、品牌 lockup）
   - `effect/blur-bg/colorwalk/polaroid/ticket` → 混合：按模板气质择一（在模板注释标注）
8. **徽标规范**：尺寸 ≥3.5% 照片高且 ≥18px；与文字行基线对齐；同模板内只出现 1 个相机徽标 + 1 个系列徽标（可选）；与文本最小间距 0.8×徽标高。

## 7. 暂停条件与回退预案

1. 某字体源不可获取/许可不明（非 OFL）→ 跳过该字体并记录，用同类替代（例外①）。
2. fonttools 实例化后引擎字重仍无差异（family 匹配问题）→ 回退：为每字重使用独立 family 名（`Inter Medium` 等）并在模板中显式引用，记录（例外③）。
3. Simple Icons 缺失的镜头品牌 → 用原创排版 lockup 补齐；原创仍不可行则隐藏该品牌徽标（不造假）（例外③）。
4. 徽标对比保护影响观感（描边/底板显脏）→ 改为「透明度+位置微调」并记录，保留对比门禁不放松。
5. wasm 体积因字体/逻辑暴涨（>2× 现值）→ 将 CJK 字体改为按需加载（仅用到时 fetch），记录（例外③）。
6. UI 墙/灯箱重做导致既有 E2E 大面积不稳定 → 保留核心断言并重写布局断言，记录（例外③）。
